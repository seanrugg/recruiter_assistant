## Download

**Windows:** download `RecruitingDesk-Setup-*.exe` below, then follow the
[install guide](https://github.com/seanrugg/recruiter_assistant/blob/main/docs/INSTALL-WINDOWS.md).

Windows will probably show "Windows protected your PC" the first time. Click
**More info → Run anyway**. The guide explains why.

The `.sha256` file lets you confirm the download is intact.
